# MasterOtter Server

Your personal media server on Home Assistant: point it at your films and shows and watch
anywhere, on the phone, the television, a PC and a browser.

- Host networking, so televisions on the LAN find it by name and remote viewing can be forwarded.
- Your files stay on `/share` or `/media`; the database and artwork live in the add-on's `/data`.
- Updates arrive through this repository like any other add-on.

Open the Web UI after the first start: the guided setup walks you through the account, the name,
the metadata key, the first library and the apps. See DOCS.md for the options.
